# 批量生成器（BatchGen）

批量调用各家 AI 接口生成图片和视频的本地小工具，内置常用接口格式，也支持完全自定义接口。整个程序就是一个单独的 exe：双击就打开自己的应用窗口，不用另外安装任何东西。

## 使用方法

1. 双击 `BatchGen.exe` 打开应用窗口，关掉窗口程序就退出。还有任务正在生成时会先询问；退出后已提交的任务下次打开会继续查询结果。
   - 窗口依赖系统的 WebView2（Windows 11 自带，Windows 10 大多已随 Edge 安装）。没有时自动改用浏览器打开，并弹出一个对话框，点「确定」退出程序。
   - 程序已经在运行时再双击：同一版本会切到已打开的窗口；换了新版本 exe 会自动让旧版本退出并接管（旧版本有任务正在生成时不会强行替换，会提示等任务完成）。接管后已打开的页面会自动刷新。侧边栏底部显示当前版本。
2. 在「设置」页面填写：
   - **接口地址**：可以带端口，比如 `http://192.168.1.10:3000`、`https://api.example.com`
   - **API Key**：可以填多个，一行一个，任务会轮流使用
   - **图片接口 / 视频接口**：从下拉框选接口格式（见下表），需要时展开「接口详情」修改
   - 填好后点「测试连接」，能拉到模型列表就说明配置对了
3. 在「新建批次」页面选择图片、视频或图转视频，然后：
   - 直接粘贴提示词，一行一条；或者
   - 导入 CSV，格式参考 `示例.csv`。用 Excel 编辑后请「另存为 → CSV UTF-8」
4. 在「任务」页面查看进度和结果，可以重试失败的任务、取消任务、打开输出文件夹。
   - **再次生成**：卡片上的按钮再生成一个，批次右上角的按钮整批再来一遍。新任务加在同一批次里，原结果保留。图转视频批次整批再次生成时只复制图片，视频在新图片完成后继续。
   - **重新编辑**：把模型、提示词、比例、时长、生成模式和参考图填回「新建批次」，改完再提交。
   - **批量选择**：批次前的复选框和顶部的「全选」用来批量删除批次；卡片左上角的复选框和批次里的「全选」用来批量删除任务，卡片右下角的垃圾桶直接删除这一个。删除只删记录，已生成的文件保留在磁盘上；进行中的任务和批次会跳过，要先取消。

生成的文件默认保存在 exe 旁边的 `outputs/` 文件夹，每个批次一个子文件夹。每个文件都配有一个同名 `.json`，里面记录了提示词、模型、参数等信息。

## 多张参考图

每个任务默认最多 4 张参考图，可以在「设置 → 运行与存储 → 参考图最多张数」里改（1–20 张）。图片会按上传顺序发送。

支持一次发多张的接口格式：OpenAI 图片接口、Chat 对话出图、Gemini 原生、豆包 Seedream、OpenAI 视频 · Seedance 扩展、NewAPI 统一视频格式。视频用糖纸的 Seedance 模型时要选「OpenAI 视频 · Seedance 扩展」，NewAPI 格式会被这些渠道拒绝。其它格式接口本身只收一张，传多张时会在创建批次时提示，不会悄悄只发第一张。首尾帧模式固定用 1 张首帧。自定义接口用 `{{images}}` 或 `"$each": "refs"` 接收多张；表单格式把文件字段名写成 `image[]` 这样以 `[]` 结尾即可。

## 网络与代理

可以在「设置 → 运行与存储 → 网络代理」里填代理地址；留空时自动使用环境变量 `HTTP_PROXY` / `HTTPS_PROXY`，再是 Windows 系统代理。

每个请求用独立的连接（HTTP/1.1），一条连接断了只影响一个任务。请求没发出去时（连不上、握手失败）会每 15 秒重试，最多 8 次，这种重试不会扣费；请求发出后连接断开不会自动重试，因为接口可能已经生成并扣费。

同步接口（如图片接口）的结果就在响应里，线路慢时要传好几分钟，卡片上会显示接收进度。程序只在接口 10 分钟没有开始响应，或传输中 2 分钟没有新数据时才判定失败，数据还在传就会一直等，不会丢掉已扣费的结果。

## 自动更新

程序启动时和之后每 6 小时检查一次新版本，也可以点侧边栏的「检查更新」。有新版本时窗口顶部提示，点「立即更新」后下载、校验，任务全部完成后自动替换并重启，设置和任务记录不动。

更新包用 ed25519 签名：公钥写在程序里，私钥只在发布者电脑上（`F:\\Keys\\batchgen-update.key`），验证不过的更新不会安装。**私钥丢了以后，已安装的程序就收不到更新了，请单独备份；也不要把它放进项目目录或发给别人。**

下载顺序：设置里的「更新镜像地址」（填了才有）→ 直连 GitHub → 内置镜像（`gh-proxy.com`、`ghfast.top`）。一个来源不通就换下一个；更新包有签名校验，镜像改不了内容。公共镜像不保证长期可用，失效时可以在设置里换一个，地址格式是能把 GitHub 地址拼在后面的前缀。

程序需要对自己所在的文件夹有写入权限，放在 `Program Files` 里无法自动更新。

## 图转视频

先批量出图，再用满意的图批量生成视频。

1. 「新建批次」选「图转视频」，写图片提示词，再写一句所有图片共用的视频提示词。想逐行不同就用 CSV 的 `video_prompt` 列，写了的行优先；都没写时用图片的提示词。
2. 分别选图片模型和视频模型。比例只选一次，图片和视频共用（16:9 的图发 1536x864，视频发 16:9），也可以手动输入图片尺寸。
3. 「每张图生成视频」默认 4 个，可以调到 1–20 个。
4. 图片完成后批次会停下来等你挑图：在缩略图左上角勾选满意的，不满意的点「重新生成」，然后点「生成视频」，确认提示词、模型、时长和数量。勾选「不挑图」时，图片完成后直接生成视频。
5. 任务页里图片和它的视频排在一起，文件名也带图片序号（`001_视频1_…`），在文件夹里同样排在一起。

普通图片批次里的已完成图片也能勾选，用同样的方式生成视频。同一张图可以再选一次，追加更多视频；已经生成过视频的图片不能重新生成，否则图片和视频对不上。

本地图片要转成网址时走「参考图上传」的图床。litterbox 是公开的，保留期内拿到链接的人都能看到图片；介意的话改用自己的存储。

## CSV 列

| 列名 | 中文别名 | 说明 |
|---|---|---|
| prompt | 提示词 | 必填 |
| type | 类型 | image / video（或 图片 / 视频），留空则用表单上选的类型 |
| model | 模型 | 留空用表单或设置里的默认模型 |
| size | 尺寸 | 如 1024x1024、1280x720 |
| duration | 时长 | 视频秒数 |
| image | 参考图 | 网址或本地绝对路径，多张用 `\|` 分隔 |
| count | 数量 | 这一行生成几份 |
| mode | 模式 | 视频生成模式：references / frames（或 全能参考 / 首尾帧），留空用表单的选择 |
| last_image | 尾帧 | 首尾帧模式的尾帧：网址或本地绝对路径 |
| video_prompt | 视频提示词 | 图转视频时这一行的视频提示词 |

## 内置接口格式

| 类型 | 格式 | 说明 |
|---|---|---|
| 图片 | OpenAI 图片接口 | `/v1/images/generations`，带参考图走 `/v1/images/edits`（gpt-image、dall-e、多数中转站） |
| 图片 | Chat 对话出图 | `/v1/chat/completions`，适合 nano-banana（Gemini 2.5 Flash Image）、GPT-4o 等，从回复里提取图片 |
| 图片 | Gemini 原生 | `/v1beta/models/{model}:generateContent`，鉴权 `x-goog-api-key` |
| 图片 | 火山方舟 Seedream（即梦） | `/api/v3/images/generations` |
| 图片 | 可灵 图片 | 异步，`/v1/images/generations` |
| 图片 | 通义万相 文生图 | 异步，DashScope `text2image/image-synthesis` |
| 图片 | Midjourney（MJ Proxy） | 异步，`/mj/submit/imagine` + `/mj/task/{id}/fetch` |
| 视频 | OpenAI 视频 · Seedance 扩展（默认） | `/v1/videos`，JSON 传参考图和首尾帧，本地图片先传图床 |
| 视频 | NewAPI 统一格式 | `/v1/video/generations`，结果地址自动识别。New API 上绑定任务插件的 Seedance 渠道不支持，会报无可用渠道 |
| 视频 | OpenAI 视频 · Seedance 扩展（JSON） | New API 中转的 Seedance 2.x 渠道（模型类型 openai-video）：`/v1/videos` JSON 请求体，`mode` + `references` / `frames` 传参考图和首尾帧，自动带 `client_task_id`、`duration`；参考图自动先传图床 |
| 视频 | OpenAI Sora | `/v1/videos`，完成后从 `/v1/videos/{id}/content` 下载 |
| 视频 | 可灵 Kling | `text2video` / `image2video`，官方 Key 填 `AccessKey:SecretKey` 自动生成 JWT |
| 视频 | 火山方舟 Seedance（即梦） | `/api/v3/contents/generations/tasks` |
| 视频 | 通义万相 视频 | DashScope `video-generation/video-synthesis` |
| 视频 | MiniMax 海螺 v1 | `/v1/video_generation`，成功后用 `file_id` 换下载地址 |
| 视频 | MiniMax v2 | `/v2/video_generation`，结果里直接给视频地址 |
| 视频 | Google Veo | Gemini API `predictLongRunning`，以 `done=true` 判断完成 |

每种格式都可以单独填「专用接口地址」和「专用 API Key」。留空的话就用通用的地址和 Key，所以图片和视频可以走不同的平台。

## 生成模式与自动补参数

**生成模式**（新建批次里，视频才有）：

- **自动**（默认）：接口要求 `mode` 参数时自动填。一般用 `references`（全能参考：文生视频、参考图生视频）；CSV 里填了「尾帧」列的任务用 `frames`。接口不要求就不发送，对其它接口没有影响。
- **全能参考**：提交时固定带上 `mode=references`，可上传一张参考图。
- **首尾帧**：提交时固定带上 `mode=frames`，上传首帧（必填）和尾帧（可选）。内置格式里，Seedance、可灵、MiniMax、Veo、NewAPI 统一格式都已加上尾帧字段；Sora 格式会把首帧和尾帧按顺序作为两个 `input_reference` 文件上传。

CSV 也可以按行指定：`mode`（或「模式」）列填 references / frames（也认「全能参考」「首尾帧」），`last_image`（或「尾帧」）列填尾帧的网址或本地路径，`image`（或「首帧」「参考图」）列填首帧。

**自动补参数**：不同中转站、不同模型常要求额外的参数（例如某些 Seedance 2.0 渠道必须带 `mode`）。任务提交被拒、且报错里写明缺什么参数时，程序会自动挑一个值补上并重试，卡片上会注明「已自动填 xx 并重试」，并把规则记到「设置 → 附加参数」，以后这个模型提交时都会带上。中转站常常一个一个地报缺参数，程序会一个一个接着补，不用手动重试：每个任务可补的参数个数跟随批次任务数（至少 10 个），同一个参数不会重复补，所以不会反复提交。只有同一个参数补了还被拒、或者猜不出该填什么值时，卡片上才会给出可选值让你手动选。像 `client_task_id`、`request_id`、`trace_id`、`nonce` 这类「每个任务一个唯一值」的参数，会自动填 `{{uuid}}`，每次提交现生成一个新的唯一 ID。能识别「xx 为必填项（a/b）」「缺少参数 xx」「xx is required」「missing parameter xx」「xx must be one of [...]」等常见写法。这个功能可以在「设置 → 附加参数」里关闭。

**设置 → 附加参数**：用表格查看、修改、删除这些规则，也可以手动添加。模型留空表示对该类型的所有模型生效；值写 true / false / 数字时按原类型发送，其它按文字发送；值里可以用 `{{uuid}}`（每次提交生成新的唯一 ID）和 `{{job_id}}`（任务编号）；参数名可写 `a.b` 表示嵌套字段。

## 参考图上传（图床）

有些接口只接受图片网址，不接受直接发送的图片数据。这时本地参考图要先上传到图床，拿到网址再提交。New API 上的 Seedance 渠道（dola 号池）两种都收，默认直接发送，不经过图床。

接口报「只接受网址」时程序会自动改为先传图床；图床连不上或被关闭时，程序会改为直接发送并记住这个设置，不让任务卡在图床上。

- **临时图床，自动切换**（默认）：免费、不用注册。按 uguu.se（保留 3 小时）、litterbox.catbox.moe（保留 24 小时）的顺序尝试，一家失败自动换下一家，并记住能用的那家。图片在保留期内是公开的，拿到链接的人能看到。tmpfiles.org 的链接中转站下载到的是网页，不能用。
- **自己的 S3 兼容存储**：Cloudflare R2、阿里云 OSS、腾讯 COS、MinIO 等，填接口地址、Bucket、Access Key、Secret Key 和公开访问地址（阿里云 OSS 勾选「虚拟主机风格」）。
- **不上传**：需要参考图时在 CSV 里直接填图片网址。

「设置 → 参考图上传」里有「测试上传」按钮，会上传一张 8×8 的小图并用公开网址取回，确认可用。每种接口格式的「接口详情」里有「本地参考图发送方式」（直接发送 / 先上传图床）；接口报「图片 URL 格式不正确」这类错误时，程序会自动改成先上传并重试，并记住这个设置。同一张图在有效期内只上传一次。

## 自定义接口

在接口格式里选「自定义接口」，或者选一个相近的预设再改其中的字段（只要改动，就会自动变成自定义）。一个接口由下面几部分描述：

1. **提交任务**：请求方法、路径（可用 `{model}`）、请求体格式（JSON 或 multipart 表单）、请求体模板。带参考图时可以改用另一个请求。
2. **返回结果**：「任务 ID 字段」留空表示同步接口，直接从提交响应里按「结果字段」取文件；填了就是异步接口。
3. **查询任务**：查询路径（`{id}` 是任务 ID）、状态字段、成功/失败状态值、进度字段、错误字段。完成后结果里没有文件地址时，可以配置下载路径（可用 `{id}`、`{file_id}`）。
4. **鉴权与请求头**：可选 Bearer、`x-goog-api-key`、`x-api-key`、可灵 JWT 或不鉴权，还可以加额外的请求头。

**请求体模板变量**：

| 变量 | 说明 |
|---|---|
| `{{prompt}}` `{{model}}` `{{size}}` | 提示词、模型、尺寸原文 |
| `{{size_star}}` `{{width}}` `{{height}}` | 尺寸为 1280x720 时分别是 `1280*720`、1280、720 |
| `{{aspect_ratio}}` | 按尺寸推算的比例，如 `16:9`；尺寸直接填 `16:9` 也可以 |
| `{{resolution}}` `{{resolution_upper}}` | 如 `720p` / `720P` |
| `{{duration}}` `{{duration_str}}` | 时长：前者是数字，后者是字符串 |
| `{{image}}` | 参考图：有网址就用网址，否则是 data URL |
| `{{image_b64}}` `{{image_mime}}` | 参考图的纯 base64 和类型 |
| `{{image_url_or_b64}}` | 有网址就用网址，否则是纯 base64（可灵用这种） |
| `{{image_last}}` 等 | 尾帧，写法同上：`{{image_last}}` `{{image_last_b64}}` `{{image_last_mime}}` `{{image_last_url_or_b64}}` |
| `{{uuid}}` `{{job_id}}` | 每次提交生成的唯一 ID、任务编号 |

**模板规则**：

- 变量为空时，它所在的键（或数组元素）会被去掉。比如没设时长，`"duration": "{{duration}}"` 这一项就不会发出去。
- `[[ ... ]]` 是可选片段，里面有变量为空时整段删掉，例如 `"{{prompt}}[[ --ar {{aspect_ratio}}]]"`。
- 对象里写 `"$if": "image"`，表示只有带参考图时才保留这个对象，适合放在 content 数组里的图片元素上。
- 整个字符串只有 `{{duration}}`、`{{width}}`、`{{height}}` 时，会以数字发送。

**字段路径**的写法如 `data.task_result.videos.*.url`：`*` 表示所有元素，`0` 表示第一个，多个候选用 `|` 分隔。「结果字段」留空时会自动在响应里找图片或视频的地址或 base64；如果是一段文字（比如 Chat 回复），也会从里面提取 Markdown 图片和链接。

点「预览请求」可以看到用示例数据渲染出来的完整请求，不会真的发送。保存时会检查模板是否是合法 JSON、有没有拼错的变量名。

## 可靠性设计

- **不会重复扣费**：异步任务（视频、可灵图片、MJ 等）一提交成功，就立刻把远端任务 ID 写入 `jobs.json`。程序重启后会接着查询这个任务，不会重新提交。
- **自动重试有限制**：只有限流（429）、网关不可用（502/503）和连不上服务器这几种情况会自动重试。超时、500、504 不会自动重试，因为远端可能已经在生成，重试可能导致重复扣费。
- **并发批量生成**：视频默认同时提交 10 个、图片 5 个，最多 50 个；其余排队，完成一个补上一个。「新建批次」里的「同时生成」可以直接调整，对所有批次立即生效（设置里也能改）。接口限流（429）时会自动等待重试。
- **任务超时**：异步任务超过设定时间仍未完成的任务会被标记为失败，错误信息里保留远端任务 ID，方便到接口后台查询。

## 数据文件（都在 exe 同目录）

- `config.json`：设置，包括 API Key，以明文保存在本机
- `jobs.json`：任务记录
- `refs/`：上传的参考图
- `outputs/`：生成结果
- `webview-data/`：应用窗口的缓存，可以删除；`batchgen.log`：窗口组件的错误日志

## 发布新版本

1. 改 `winres/winres.json` 里的版本号（4 处，版本号相同或更低时发布工具会拒绝）。
2. 运行 `bash release.sh "这个版本的更新内容"`。

发布用的是这台电脑上已登录的 GitHub CLI（`gh`），文件放在这个公开仓库的 Releases 里，用户不用登录就能下载，这是自动更新的前提。

先把代码推送到 GitHub 再发布：`gh release create` 会把标签打在线上 `main` 的最新提交上。

1.4.1 及更早的程序内置的是已删除的旧仓库地址，无法自动更新，需要重新安装一次。

新用户的固定下载地址：

- 安装包（推荐）：`https://github.com/Roins-hub/batchgen/releases/latest/download/BatchGen-Setup.exe`
- 免安装压缩包：`https://github.com/Roins-hub/batchgen/releases/latest/download/BatchGen-win-x64.zip`

安装包不需要管理员权限，默认装到 `%LOCALAPPDATA%\Programs\BatchGen`，也可以选别的盘（Program Files 不行：程序要在安装目录里存数据和更新自己）。没有 WebView2 时会用微软的引导程序联网安装，装不上时程序改用浏览器打开。卸载只删程序和缓存，图片、视频和配置保留。

编译安装包需要两个文件，都不在项目里：

- [Inno Setup 7](https://jrsoftware.org/isinfo.php)，便携安装到 `F:\DevTools\tools\InnoSetup`：`innosetup-*.exe /VERYSILENT /CURRENTUSER /PORTABLE=1 /DIR="F:\DevTools\tools\InnoSetup"`
- [WebView2 引导程序](https://go.microsoft.com/fwlink/p/?LinkId=2124703)，放到 `F:\DevTools\dl\wv2\MicrosoftEdgeWebview2Setup.exe`

## 开发

```bash
./build.sh          # 输出 dist/BatchGen.exe
python package.py  # 把 exe 打成 release/BatchGen-<版本>-win-x64.zip，可以直接发给别人
bash installer/build.sh  # 生成安装包 release/BatchGen-<版本>-Setup.exe
bash release.sh "更新内容"  # 编译、打包、签名并发布，已安装的程序会自动收到更新
```

- 窗口：`window_windows.go`，用 go-webview2（纯 Go，不需要 CGO）。图标、版本号和高分屏声明在 `winres/`，`build.sh` 会编译成 `rsrc_windows_amd64.syso` 写进 exe；发新版本时改 `winres/winres.json` 里的版本号。
- 后端：Go 标准库，唯一的第三方依赖是上面的窗口组件。`main.go` 入口，`server.go` HTTP 接口，`worker.go` 调度，`spec.go` 接口格式与内置预设，`template.go` 请求体模板，`extract.go` 响应字段提取，`provider.go` HTTP 调用与下载，`input.go` 输入解析，`store.go` / `config.go` 持久化；`go test ./...` 跑单元测试
- 前端：`web/` 下的原生 HTML/CSS/JS，编译时嵌入 exe。字体 IBM Plex Sans / Mono（SIL Open Font License）放在 `web/fonts/`，随程序内置，离线可用
- 环境变量：`BATCHGEN_DATA` 指定数据目录，`BATCHGEN_NO_BROWSER=1` 只运行后台服务，不打开窗口，`BATCHGEN_PORT` 换一个端口运行（开发测试用，不影响正在使用的程序）
- 安全：服务只监听 127.0.0.1，会校验 Host 头，写操作要求带 `X-BatchGen` 请求头，防止其它网页借浏览器操作本地服务
