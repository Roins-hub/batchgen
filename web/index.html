默认模型

新建批次时自动填入，单个批次里可以再改。点输入框右侧的箭头可以从模型列表里选，也可以直接输入。

图片接口

选择接口格式。展开「接口详情」可以修改路径、请求体模板和返回字段。

视频接口

视频大多是异步接口：先提交拿到任务 ID，再定时查询直到完成。

参考图上传

有些接口只接受图片网址，不接受直接发送图片。用到这类接口时，本地参考图会先上传到这里拿到网址；同一张图只上传一次。

保留时长

图片会公开保存在 litterbox.catbox.moe，到期自动删除；在此期间拿到链接的人能看到图片。介意的话请改用自己的存储。图床在部分网络下连不上或拒绝上传，这不影响 Seedance 视频：传不上时程序会把图片直接随请求发送。

附加参数

有些中转站或模型要求额外的参数（比如 mode）。按模型加在这里，提交时会自动带上。接口提示缺少参数时，程序自动补上的规则也会记在这里。

类型模型（留空 = 全部）参数名值

还没有附加参数。大多数接口不需要。

值写 true / false / 数字时按原类型发送，其它按文字发送；值里可以用 {{uuid}}（每次提交生成一个新的唯一 ID）、{{job_id}}（任务编号）；参数名可以写 a.b 表示嵌套字段。

运行与存储

并发数太高可能触发接口限流；只有限流和网关错误会自动重试，避免重复扣费。

生图结果每张有好几 MB，线路慢时会传很久甚至断开。留空时自动使用系统代理；代理软件没开系统代理时，把它的端口填在这里。
